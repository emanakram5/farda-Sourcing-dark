MAIN BRANCH SOURCE FINDINGS
- React 18 and React Router 6 application built with Vite 5 and plain CSS.
- Dependencies include Framer Motion, Three.js, and Lucide React.
- App.jsx mounts Scene3D, Preloader, ScrollToTop, ScrollReveal, navigation,
  route content, and the footer.
- Home includes cinematic content, animated counters, and viewport reveals.
- Products includes category filtering, a rotating showroom driven by scroll,
  previous/next controls, and quote links.
- Services presents an animated shipment route and service stations.
- Process and supplier criteria use scroll-driven vertical presentations.
- The navbar changes appearance and visibility during scrolling and supports
  a mobile menu.
- Global styles import variables.css, base.css, motion.css, and cinematic.css.
  There is no responsive.css in the reviewed main baseline.
- Routes include Home, About, Products, Services, Markets, How It Works,
  Supplier, Contact, Franchise, and a fallback 404.

EXISTING INTEGRATION LIMITS
- Inquiry submission in src/services/api.js logs the submitted data and returns
  a delayed resolved promise; it does not deliver a backend request.
- The newsletter validates locally and displays a success message; its external
